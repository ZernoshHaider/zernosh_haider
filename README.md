# Zernosh Haider - Next.js Project

A modern, high-performance web application built with **Next.js 14 (App Router)**, **React 18**, **TypeScript**, and a custom **Glassmorphism CSS Design System**.

---

## 🚀 Quick Start Guide

### 1. Open Terminal in the Project Directory
```bash
cd C:\Users\HP\.gemini\antigravity-ide\scratch\zernosh_haider
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application live.

## ✨ Features Included

- **Next.js 14 App Router**: Powered by Server Components & Client Hooks.
- **Glassmorphism Design System**: Dynamic background glowing orbs, blur panels, and sleek dark mode palette.
- **TypeScript Ready**: End-to-end type safety for props and data models.
- **Responsive Layout**: Designed for seamless experience across mobile, tablet, and desktop.
- **SEO & Meta Tags**: Pre-configured metadata and heading structure.
